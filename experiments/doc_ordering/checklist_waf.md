# Before you start: Configuring logging for a protection pack (web ACL)

Generated by `reorder.py` from `chain_waf.json` (6 pages). Do the items in order; each one comes after the things it depends on.

## Required

1. **iam identity policy**: Permissions for the user managing AWS WAF to configure logging and log delivery (e.g. AWSWAFConsoleFullAccess or AWSWAFFullAccess managed policy, or an equivalent identity-based policy with wafv2, logs and s3 actions)
   - asked for by [Sending protection pack (web ACL) traffic logs to an Amazon Simple Sto](https://docs.aws.amazon.com/waf/latest/developerguide/logging-s3.html), 2 pages from the start; steps: https://docs.aws.amazon.com/IAM/latest/UserGuide/access.html
2. **s3 bucket**: Amazon S3 bucket for logging, in the same account that manages the protection pack (web ACL), with a name starting with aws-waf-logs-
   - asked for by [Sending protection pack (web ACL) traffic logs to an Amazon Simple Sto](https://docs.aws.amazon.com/waf/latest/developerguide/logging-s3.html), 2 pages from the start; steps: https://docs.aws.amazon.com/AmazonS3/latest/userguide/CreatingABucket.html
3. **tool or access**: AWS Management Console access with permissions to sign in and view or edit the bucket's policy
   - asked for by [Adding a bucket policy by using the Amazon S3 console](https://docs.aws.amazon.com/AmazonS3/latest/userguide/add-bucket-policy.html), 3 pages from the start; no steps given
4. **bucket policy**: Bucket policy allowing the log delivery service (delivery.logs.amazonaws.com) to write logs to the bucket; added automatically if the creator owns the bucket and has GetBucketPolicy/PutBucketPolicy, otherwise the bucket owner must add it manually (may be created for you)
   - asked for by [Sending protection pack (web ACL) traffic logs to an Amazon Simple Sto](https://docs.aws.amazon.com/waf/latest/developerguide/logging-s3.html), 2 pages from the start; steps: https://docs.aws.amazon.com/AmazonS3/latest/userguide/add-bucket-policy.html

## Only in some setups

1. **account or service setting**: Delegated administrator for IAM Access Analyzer when used within an AWS Organizations organization
   - asked for by [Getting started with AWS Identity and Access Management Access Analyze](https://docs.aws.amazon.com/IAM/latest/UserGuide/access-analyzer-getting-started.html), 4 pages from the start; steps: https://docs.aws.amazon.com/IAM/latest/UserGuide/access-analyzer-delegated-administrator-add.html
2. **iam identity policy**: Permissions for the account/identity to configure and use IAM Access Analyzer (e.g., IAMAccessAnalyzerFullAccess or ReadOnlyAccess managed policy attached to the IAM identity)
   - asked for by [Getting started with AWS Identity and Access Management Access Analyze](https://docs.aws.amazon.com/IAM/latest/UserGuide/access-analyzer-getting-started.html), 4 pages from the start; steps: https://docs.aws.amazon.com/IAM/latest/UserGuide/security-iam-awsmanpol.html
3. **iam identity policy**: Permissions to view the findings dashboard (GetAnalyzer, ListAnalyzers, GetFindingsStatistics actions)
   - asked for by [Getting started with AWS Identity and Access Management Access Analyze](https://docs.aws.amazon.com/IAM/latest/UserGuide/access-analyzer-getting-started.html), 4 pages from the start; steps: https://docs.aws.amazon.com/IAM/latest/UserGuide/access-analyzer-dashboard.html
4. **iam role**: Service-linked role AWSServiceRoleForAccessAnalyzer (created automatically when an analyzer is created) (may be created for you)
   - asked for by [Getting started with AWS Identity and Access Management Access Analyze](https://docs.aws.amazon.com/IAM/latest/UserGuide/access-analyzer-getting-started.html), 4 pages from the start; steps: https://docs.aws.amazon.com/IAM/latest/UserGuide/access-analyzer-using-service-linked-roles.html
5. **other aws resource**: An active IAM Access Analyzer account analyzer (only needed for the optional Preview external access step)
   - asked for by [Adding a bucket policy by using the Amazon S3 console](https://docs.aws.amazon.com/AmazonS3/latest/userguide/add-bucket-policy.html), 3 pages from the start; steps: https://docs.aws.amazon.com/IAM/latest/UserGuide/access-analyzer-getting-started.html
6. **kms key policy**: KMS key policy allowing AWS WAF logging to use the customer managed KMS key, required only if the bucket uses SSE-KMS encryption with a customer managed key
   - asked for by [Sending protection pack (web ACL) traffic logs to an Amazon Simple Sto](https://docs.aws.amazon.com/waf/latest/developerguide/logging-s3.html), 2 pages from the start; steps on the page

Then follow [Configuring logging for a protection pack (web ACL)](https://docs.aws.amazon.com/waf/latest/developerguide/logging-management-configure.html).
